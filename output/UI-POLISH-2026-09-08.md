## Limits

Browser work used a disconnected wallet. Connected-wallet dropdown, wrong-network and transaction-signing flows were not exercised live. Their presentation changes were reviewed in source; existing regression tests passed. Reduced-motion/coarse-pointer rules were source-checked; viewport resizing alone is not real touch-device emulation.

An upstream testnet RPC log request timed out during development; the pool API still returned HTTP 200 and the pool view subsequently displayed data in production. Network freshness remains dependent on the testnet services. No public deployment was performed.
