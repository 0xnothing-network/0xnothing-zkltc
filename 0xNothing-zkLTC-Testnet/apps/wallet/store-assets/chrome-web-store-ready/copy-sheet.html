Sử dụng dữ liệu — tick đúng các ô dưới đây
  • Leave Personally identifiable information (No)
    The wallet asks for no name, email, postal address, phone or ID; wallet addresses are disclosed under Financial and payment information.
  • Leave Health information (No)
    None handled.
  • Tick Financial and payment information (Yes)
    Wallet addresses, balances, transactions and signed transactions are handled; addresses and signed transactions go to the RPC to read the chain and broadcast. To show the 24-hour change on Home, the 0xNothing API (or Goldsky) is asked for the price history of 0xPump tokens the account holds, by token contract address, never by wallet address.
  • Tick Authentication information (Yes)
    The password, recovery phrase and private keys are handled and stored on the device in an encrypted vault; they are never sent.
  • Leave Personal communications (No)
    No email, chat or messages are read; a message a site asks the user to sign is covered under Website content.
  • Leave Location (No (owner decides))
    The code reads no location; servers see the IP address of each request only as part of the connection. See "Only the owner" item 7.
  • Tick Web history (Yes)
    The wallet stores the origins of sites the user connected and of sites that sent requests, and reads the active tab's origin when the popup opens (activeTab); kept on the device only.
  • Leave User activity (No)
    No clicks, keystrokes, scrolling or network traffic of the user are monitored; in-wallet actions such as the last tab or swap pair stay on the device as settings.
  • Tick Website content (Yes)
    Requests a website sends (transactions, messages and typed data to sign, token and network suggestions, page title) are stored in the local approval queue and shown to the user; not sent to the developer. Public read calls a website makes through the provider (for example eth_call, eth_getBalance) are forwarded to the active RPC, which is how every injected wallet answers them.

6. Owner's own steps Việc chỉ anh làm

Việc của chủ dự án

1. Privacy policy. The public policy is at `https://0xnothing.app/privacy` (`apps/web/app/privacy/page.tsx`). The page in the repository was updated for 1.0.10 on 2026-11-15 and closes the gaps listed below; the live site keeps showing the version of August 30, 2026 until the web app is deployed. Deploy it before you submit. The gaps it closes: - Chrome permissions lists only storage, alarms and host access. Add idle (locks on computer lock), sidePanel, activeTab (reads the current tab's origin when the popup opens, not stored) and the optional notifications permission; alarms also run auto-lock and the transaction watch. - It does not say that the content scripts run on every http and https page and frame to expose the provider. - Network requests do not name the IPFS image gateways (dweb.link, ipfs.io, gateway.pinata.cloud, mypinata.cloud), the 0xNothing image proxy, the LiteForge RPC override, or that a website can make public read calls to the RPC through the provider. - Data handled misses saved recipient names, the token approval records, notification texts and shown ids, the requesting page's title, the 10-minute send draft, and the CSV export (a file saved by the user). - The Home screen asks the 0xNothing API (or Goldsky) for the price history of the 0xPump tokens the account holds, by token contract address; together with the request's IP address that tells the server which of those tokens a user holds. Say so. - A transaction notification for a website's transaction shows that site's host name ("Request from ..."), and notification texts are cached on the device. - A website can suggest a network; when the user approves it, its RPC receives the same requests as any custom RPC. - Locking: add the auto-lock default (15 minutes, choices 1 to 60) and the lock on computer lock. - Add the affirmative Limited Use sentence, for example: "The use of information received by 0xWallet complies with the Chrome Web Store User Data Policy, including the Limited Use requirements." - Add that test assets have no monetary value, and the new effective date.
